# 接龙 / 团购导入 Excel 模板说明

**文件：** [`yiyi-jielong-import-template.xlsx`](./yiyi-jielong-import-template.xlsx)  
**工作表：** `接龙导入模板`（表头冻结 + 4 行假数据示例）· `字段说明`  
**仓库副本（可选）：** `templates/yiyi-jielong-import-template.xlsx` on `vercel-next`

## 设计原则

1. **一行 = 一件商品**（含单独的「送货费」行）；禁止一格多 SKU。
2. **前 6 列对齐现有 Google Sheet / 导入重映射：**  
   `到货情况 | 付款情况 | 订单号 | 客户姓名 | 商品 | 金额`  
   （`toSheetCells` 写回时也按这 6 格重排，其后原样追加 `originalRow.slice(6)`。）
3. **电话 / 地址 / ZIP 放在第 7 列起**，以便在**不加代码**时仍能被当前尾列启发式识别，并在 append 时保留。
4. **税季字段**放在右侧（表头青绿色），运营导入可留空，报税季再填或导出。
5. 示例数据全部虚构，无真实客户 PII。

## 与当前导入 / Google Sheet 的映射

**现有 `HEADER_ALIASES`（`lib/sheets/headers.ts`）已覆盖：**

| 模板列 | 别名族 |
|--------|--------|
| 客户姓名 | name ← 姓名/客户姓名/客户/微信名/customer/customer_name |
| 商品 | content ← 内容/商品内容/商品明细/商品/items/description |
| 金额 | amount ← 总价/金额/订单金额/total/amount |
| 到货情况 | arrival ← 到货情况/到货状态/arrival/arrival_status |
| 付款情况 | payment ← 付款情况/付款状态/payment/payment_status |
| 订单号 | orderNumber ← 序号/订单号/订单编号/order_id/order_number |

**Google Sheet 订单 tab（自提 / 邮寄 / 三谷 / 95008）** 规范头与 mock 一致为：  
`到货情况, 付款情况, 序号, 姓名, 内容, 总价` + 尾列扩展。  
本模板用「订单号/客户姓名/商品/金额」——均已在别名表中，导入后 commit 会写成上述 6 列顺序。

**区域 tab 分流：** `proposeImportTab` 优先精确 ZIP 种子 → `三谷`/`95008`；否则按内容里的自提/送货费 → `自提`/`邮寄`；冲突或未定则 needs_review。

**履约兼容写法（当前代码）：**

- 自提：至少一行 `商品` 含 `自提` 或 `自取`（示例已写）。
- 邮寄：单独一行 `商品=送货费`（示例第 3 行），不要只写「邮寄」在履约列就指望分类通过。
- `履约方式` 列的 `自提`/`邮寄` 可被 `routeForSheet` 扫到，但 **`classifyFulfillment` 仍只看 `content`**。

## 与当前导入器的缺口

### 已做的最小代码修复（本任务）

- `lib/import/xlsx.ts`：正确解析 openpyxl 风格的空单元格（`<c … />` / `<c … />`），避免空白「到货情况」把「付款情况」左移。

### 仍建议下一步加 aliases + 读列（先文档、再改 parse）

| 字段 | 建议 aliases | 说明 |
|------|--------------|------|
| 电话 | `电话`, `手机`, `联系电话`, `phone` | 取代尾列正则；归组 phone+name |
| 地址 | `地址`, `收件地址`, `address` | Shippo / 邮寄 |
| 城市 | `城市`, `city` | |
| 州 | `州`, `state` | |
| ZIP | `ZIP`, `邮编`, `邮政编码`, `zip` | **优先于**尾列 `\b\d{5}\b` 猜测（避免街道号陷阱） |
| 数量 | `数量`, `qty`, `quantity` | 一行一件后可不再依赖「商品×N」 |
| 单价 | `单价`, `unit_price`, `price` | |
| 履约方式 | `履约方式`, `配送方式`, `fulfillment` | 读列后可减少往商品里塞标记 |
| 区域 | `区域`, `region` | 人工标注；仍以 ZIP 提案为准做校验 |
| 交易日期等税季列 | `交易日期`/`transaction_date`, `付款方式`/`payment_method`, `收款状态`, `税率`/`tax_rate`, `税额`/`tax_amount`, `发票号`/`收据号`/`invoice_number`, `成本`/`cost`, `平台费`/`platform_fee`, `运费`/`shipping_fee` | 导入可原样进 `originalRow`；报税导出或未来账本 tab 再用 |

### 去重与一行一件

`previewImport` 目前按**订单号**全局去重：同一 `订单号` 的第二行会 `skipped_duplicate`。  
因此示例用 `JL-2026-1102-1` / `JL-2026-1102-2`。理想模型是同单共享订单号、按「姓名+商品+金额」签名去重——**应作为下一刀 dedupe 调整**，与 aliases 一并做。

**推荐优先级：**  
1) **电话 / ZIP / 地址 / 数量 / 履约方式** aliases + parse 读列  
2) 行项目友好的订单号去重（允许多行同号，仅跳过内容签名重复）  
3) 税季列继续放 Excel / `originalRow`，暂不进 `OrderRow`

## 操作员用法（短）

1. 复制本 xlsx → 删掉示例行 → 按接龙录入（一行一件）。
2. 邮寄订单：商品行 + 单独「送货费」行；**当前**每行订单号需唯一（可用 `-1`/`-2`），客户/地址/ZIP 保持一致。
3. 自提：`履约方式=自提`，并在过渡期于 `商品` 含「自提」字样。
4. 填准 ZIP（94506/94566/94568/94588 → 三谷；95008/95032/… → 95008）。
5. 工作台 **接龙导入** → 预览 → 确认追加（非整表替换）。只导入 `接龙导入模板` 工作表（或另存为单表）；`字段说明` 勿当订单导入。
6. 到货/付款仍在 Sheet / 状态面板确认写回；税季列可事后补。
